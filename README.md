## How to Compile & Run

Using GCC (MinGW / MSYS2 on Windows, or `gcc` on Linux/macOS):

```bash
gcc program.c -o program
./program        # Linux / macOS
program.exe      # Windows
```

Or with a single step:

```bash
gcc program.c -o program && ./program
```

## Naming Convention

- Practice files: `ch01_hello_world.c`, `ch06_factorial.c`
- Notes: `notes/chapter-01.md` or `chapters/chapter-01/notes.md`
- Keep one main idea per `.c` file
